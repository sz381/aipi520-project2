# Project 2 背景：这个项目到底要干嘛

> 给团队看的中文入门讲解。来源：Project 2 slides 和 10/21 课堂讲稿。

## 1. 新药是怎么上市的

一个新药要卖给病人，必须先在人身上做临床试验，一共三关：

| 阶段 | 测什么 | 大概花多少钱 |
|---|---|---|
| **Phase 1** | 安不安全（几十个人，小剂量） | 500–1000 万美元 |
| **Phase 2** | 有没有效，剂量多少合适（几百人） | 2000–3000 万美元 |
| **Phase 3** | 在更多人身上确认确实有效（几千人） | 几亿美元 |

三关都过了，FDA 才批准上市。每一关的结果基本只有**成功或失败**两种，失败了钱就全打水漂。

所以很多人都想**提前知道一个试验能不能成功**：药企想知道值不值得继续砸钱；投资人想知道该不该投；大药企想知道该不该收购（小公司通常在 Phase 2 做完、Phase 3 之前被收购）。

## 2. 任务

做一个"算命机器"：**输入一个临床试验的信息，输出它成功的概率**。本质上是二分类，模型输出 P(y=1)。

## 3. 数据

ClinicalTrials.gov 登记了全世界大部分临床试验。`data/raw/` 里的 61 万个 XML 文件，每个是一个试验的"简历"：编号、阶段、治什么病、用什么药、招多少人、在哪做、谁出钱、当前状态……

## 4. 难点：没有答案

数据库只有 X（特征），**没有 y（成功还是失败）**，y 得自己造。老师课上给的办法：

- **看后来有没有下一期**：Phase 2 之后出现了同药同病的 Phase 3，说明 Phase 2 成功了（我们用的就是这个）；
- 用别人论文里标好的数据（HINT 论文的 TOP 数据集）；
- Phase 3 的话，查 FDA 数据库看药有没有上市；
- 爬新闻，让 LLM 判断成败。

## 5. Scope 怎么定

老师**故意**没规定范围：可以做通用模型（他说最难），也可以缩小到某一期、某个病种。评分看的是**你们怎么定的范围、为什么这么定**，不是做得越宽越好。

我们最后选的是**"一个新药的闯关之路"**：只看药企发起的试验、只看新药，一关一个模型（Phase 1 → 2、Phase 2 → 3、Phase 3 → FDA 批准）。原因：
1. 三关正好对应老师课上给的三种造标签方法；
2. 三关正好对应三类关心这个问题的人（早期投资人、收购方、准备上市的大药企）；
3. 结果都不错（AUC 0.72 / 0.72 / 0.81），而且"越往后越好预测"本身就是一个好的解读点；
4. 一人一关，分工自然。

详细讲解见 [02_walkthrough_zh.md](02_walkthrough_zh.md)。

- **2–4 页 writeup**：**必须自己写，不能用 AI**；
