Features

80 features, all known at trial start

Drug history

trials so far, years since first trial, conditions tested

Trial design

randomised, blinding, arms, placebo, number of endpoints

Disease

12 therapeutic areas, past success rate in the condition

Sponsor

earlier trials, past Phase 2 → 3 rate

Geography

sites and countries; US, Europe, East Asia

Eligibility

criteria length and count, ages, healthy volunteers

Text

TF-IDF of title, summary and primary outcomes

Never used

actual enrollment, status, posted results: they leak the answer

Every history feature only counts trials that started before this one, so the model never sees the future.

- Seven groups plus text. Drug history matters most, as the next slides show. - Time-safe: counts such as “trials of this drug so far” only look backward from the trial start date. - Deliberately excluded: actual enrollment (terminated trials enrol fewer people), status and results. Adding them would raise AUC dishonestly.
