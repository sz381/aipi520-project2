Honesty checks

Is the score real?

Random splits flatter: random 5-fold CV adds +0.08 at Phase 3, because one drug’s trials share one approval. We report the temporal split.

Unseen drugs: on test drugs never seen in training, AUC stays at 0.70 / 0.72 / 0.80, so the model is not memorising names.

Leaky features out: actual enrollment or trial status would inflate AUC; we never use them.

18 framings explored: the ones that score higher mix easy populations (appendix).

- The same model scores 0.883 at Phase 3 with a random split vs 0.802 with the honest temporal split: the random split lets the model see other trials of the same drug, which share one approval outcome. - Test drugs never seen in training score almost the same, so the model learns patterns, not drug names. - Features that only exist after a trial ends (actual enrollment, status, posted results) are excluded. - We tried 18 framings; several reach 0.79 to 0.85 but only because they mix in easy cases, such as mature drugs or academic trials.
